### 1. FIPO: Eliciting Deep Reasoning with Future-KL Influenced Policy Optimization

**트랙**: RL for LLMs / Reasoning | **링크**: [arXiv](https://arxiv.org/abs/2603.19835)

📋 Problem Definition

GRPO 계열의 강화학습 알고리즘은 결과 기반 보상(ORM)에 의존하기 때문에, trajectory 내 모든 토큰에 동일한 advantage를 부여하는 coarse-grained credit assignment 문제를 갖는다. 이로 인해 핵심적인 논리적 전환점(logical pivot) 토큰과 사소한 토큰이 구별되지 않아, 모델이 일정 길이 이상의 chain-of-thought를 생성하지 못하고 정체(length stagnation)하는 성능 천장이 발생한다. FIPO는 value network 없이도 토큰 수준의 dense advantage를 구성하여 이 병목을 해소하고, base model에서 장문 추론 능력을 끌어내는 것을 목표로 한다.

📚 Background / Related Works

GRPO(Shao et al., 2024)는 value network 없이 그룹 샘플링 기반으로 advantage를 추정하지만, 시퀀스 전체에 균일한 advantage를 broadcast하는 한계가 있으며, DAPO(Yu et al., 2025)는 비대칭 클리핑과 동적 샘플링으로 GRPO를 개선했지만 여전히 동일한 credit assignment 문제를 공유한다. PPO 기반 접근인 Open-Reasoner-Zero(Hu et al., 2025), VC-PPO(Yuan et al., 2025), VAPO(Yue et al., 2025), T-PPO(Fan et al., 2025)는 GAE를 통해 토큰별 dense advantage를 제공하지만, value model이 필요하며 특히 VC-PPO/VAPO/T-PPO는 Long-CoT SFT 데이터로 사전학습된 value model에 의존하여 성능 향상의 원천이 알고리즘 자체인지 value model의 사전 지식인지 분리가 어렵다. 저자들의 선행 연구(Meng et al., 2025; Huang et al., 2025)에서는 RL 학습 중 98% 이상의 토큰에서는 분포 변화가 없고 극소수의 sparse하고 critical한 토큰에서만 정책이 개입한다는 사실, 그리고 signed log-probability difference가 최적화 방향의 지표가 된다는 사실을 밝혔으며, 이것이 FIPO의 직접적 동기가 되었다.

🔬 Main Methodology

FIPO의 핵심은 각 토큰 t에서의 확률 변화량 Δlog p_t = log π_θ(o_t|...) - log π_θ_old(o_t|...)를 원자적 신호로 삼고, 이를 미래 시점까지 누적한 Future-KL_t = Σ_{k=t}^{T} M_k · γ^{k-t} · Δlog p_k를 정의하는 것이다. 여기서 γ = 2^{-1/τ}는 half-life τ를 갖는 지수 감쇠 계수로, 가까운 미래 토큰에 더 큰 가중치를 부여하는 soft decay window를 형성하며, M_k는 importance ratio가 Dual-Clip 임계값 c(보통 c≥10)를 초과하는 토큰을 제거하는 이진 마스크로 학습 불안정성을 방지한다. 이렇게 계산된 Future-KL_t를 exp() 매핑 후 [1-ε_f_low, 1+ε_f_high] 범위로 클리핑하여 influence weight f_t를 구하고, 기존 group-relative advantage A_hat_t에 f_t를 곱해 수정된 advantage A_tilde_t = A_hat_t · f_t를 만든다. 이 방식의 핵심 직관은, 미래 trajectory 전체가 현재 정책에 의해 강화(FutureKL > 0)되고 있는 토큰은 후속 추론 체인의 안정적 기반이므로 advantage를 증폭시키고, 반대로 미래가 억제(FutureKL < 0)되는 토큰은 advantage를 감쇠시켜, value model 없이도 토큰별로 차별화된 dense credit assignment를 달성한다는 것이다. 추가로 negative advantage(A_hat < 0)이면서 importance ratio가 과도하게 큰 토큰에 대해서는 f_t를 1로 리셋하여 과도한 페널티를 방지한다.

🧪 Evaluation

Qwen2.5-32B-Base 모델에 DAPO의 공개 학습 데이터셋을 사용하여 순수 RL만으로 학습하였으며, AIME 2024 Pass@1에서 DAPO 기준선의 50.0%에서 피크 58.0%(수렴 시 약 56.0%)까지 정확도를 향상시켰고, 이는 DeepSeek-R1-Zero-Math-32B(약 47.0%)와 o1-mini(약 56.0%)를 상회하는 결과이다. 동시에 평균 chain-of-thought 길이가 약 4,000 토큰에서 10,000 토큰 이상으로 점진적으로 확장되었으며, 이는 DAPO에서 관찰되는 길이 정체 현상을 돌파한 것이다. value model 사전학습이나 Long-CoT SFT 데이터 없이 순수 RL만으로 이러한 성능을 달성했다는 점에서, PPO 기반 방법들(VC-PPO, VAPO, T-PPO)과 동등하거나 우수한 결과를 value model의 외부 지식 없이 얻었다.

💡 Key Intuition & Lesson

이 논문의 핵심 통찰은 "credit assignment의 밀도(density)가 추론 깊이의 병목"이라는 것이다. ORM 기반 알고리즘에서 모든 토큰에 균일한 보상을 주는 것이 장문 추론 학습의 근본적 한계이며, 별도의 value network를 도입하지 않더라도 정책 자체의 확률 변화를 미래 방향으로 누적(Future-KL)함으로써 각 토큰의 하류 영향력을 추정할 수 있다는 것을 보여준다. 또한 이러한 누적 신호를 안정적으로 사용하려면 지수 감쇠(soft decay window), Dual-Clip 마스킹, influence weight 클리핑이라는 삼중 안전장치가 필수적이며, 이 중 하나라도 빠지면 gradient norm 폭발과 응답 길이 붕괴가 발생한다는 실험적 교훈을 제공한다. 이는 GRPO 계열 알고리즘의 진화 방향으로서, value model의 복잡성 없이 dense advantage를 구성하는 것이 base model의 잠재적 추론 능력을 해방하는 실용적 경로임을 시사한다.

### 2. Unify-Agent: A Unified Multimodal Agent for World-Grounded Image Synthesis

**트랙**: Agents | **링크**: [arXiv](https://arxiv.org/abs/2603.29620)

📋 Problem Definition

통합 멀티모달 모델(unified multimodal model)은 이미지 이해와 생성을 하나의 아키텍처에서 수행할 수 있지만, 학습 시 고정된 파라메트릭 지식(frozen parametric knowledge)에 주로 의존하기 때문에 롱테일(long-tail) 개념이나 지식 집약적(knowledge-intensive) 개념이 포함된 실세계 이미지 생성에서 심각한 한계를 보인다. 예를 들어, 특정 문화유산, 희귀 동식물, 잘 알려지지 않은 역사적 인물 등 학습 데이터에 충분히 노출되지 않은 개념을 정확하게 시각화하는 것이 어렵다. 본 논문은 이러한 한계를 에이전트 기반 모델링(agentic modeling)으로 극복하고자 한다.

📚 Background / Related Works

이 연구는 크게 세 갈래의 선행 연구 위에 구축된다. 첫째, 이해와 생성을 통합하는 멀티모달 모델로서 Janus, SEED-X, Emu3, Transfusion 등이 텍스트-이미지 생성과 시각 이해를 단일 모델에서 수행하는 아키텍처를 제안해왔다. 둘째, LLM 기반 에이전트 연구로서 Toolformer, ReAct, WebGPT 등이 외부 도구 호출과 검색을 통해 모델의 지식 한계를 보완하는 패러다임을 확립했다. 셋째, 지식 기반 이미지 생성 분야에서 RPG, LLM Blueprint 등이 LLM을 플래너로 활용해 생성 품질을 높이는 접근을 시도했으나, 이들은 외부 멀티모달 증거 검색과 통합 모델 내 에이전틱 파이프라인을 결합하지는 못했다.

🔬 Main Methodology

Unify-Agent는 이미지 생성을 네 단계의 에이전틱 파이프라인으로 재구성한다: (1) 프롬프트 이해(prompt understanding) 단계에서 사용자의 텍스트 입력을 분석하여 지식 보강이 필요한 개념을 식별하고, (2) 멀티모달 증거 검색(multimodal evidence searching) 단계에서 외부 소스로부터 해당 개념에 대한 텍스트 및 이미지 증거를 수집하며, (3) 그라운디드 리캡셔닝(grounded recaptioning) 단계에서 검색된 증거를 바탕으로 원래 프롬프트를 사실에 기반한 상세 캡션으로 재작성하고, (4) 최종 합성(final synthesis) 단계에서 이 정보를 종합하여 이미지를 생성한다. 학습을 위해 맞춤형 멀티모달 데이터 파이프라인을 구축하고, 전체 에이전틱 생성 과정에 대한 지도 학습이 가능하도록 143K개의 고품질 에이전트 궤적(agent trajectory) 데이터를 큐레이션했다. 이 궤적 데이터는 각 단계별 중간 출력(검색 쿼리, 검색 결과, 재작성된 캡션 등)을 모두 포함하여, 모델이 단순히 최종 이미지만이 아니라 전체 추론-검색-생성 과정을 학습할 수 있게 한다.

🧪 Evaluation

저자들은 FactIP라는 새로운 벤치마크를 제안했는데, 이는 문화적으로 중요하거나 롱테일에 해당하는 사실적 개념 12개 카테고리를 포함하며, 외부 지식 그라운딩을 명시적으로 요구하는 평가 체계이다. 다양한 기존 벤치마크와 실세계 생성 과제에서 실험한 결과, Unify-Agent는 베이스 통합 모델 대비 상당한 성능 향상을 달성했으며, 가장 강력한 폐쇄형 모델(closed-source model)의 세계 지식 역량에 근접하는 수준을 보였다. 특히 롱테일 개념의 시각적 정확도와 사실적 일관성에서 기존 오픈소스 모델 대비 의미 있는 격차를 보여주었다.

💡 Key Intuition & Lesson

핵심 인사이트는 이미지 생성 모델의 지식 한계를 모델 파라미터 확장이 아닌 에이전틱 파이프라인(추론-검색-생성의 긴밀한 결합)으로 해결할 수 있다는 점이다. 이는 LLM 분야에서 RAG(Retrieval-Augmented Generation)가 가져온 패러다임 전환을 이미지 생성 영역으로 확장한 것으로, 생성 모델도 "알고 있는 것을 그리는" 방식에서 "필요한 지식을 찾아서 그리는" 방식으로 전환될 수 있음을 보여준다. 또한 143K 궤적 데이터를 통한 전체 파이프라인 지도 학습이라는 접근은, 에이전트 시스템을 end-to-end로 훈련 가능하게 만드는 데이터 엔지니어링의 중요성을 다시 한번 확인시켜 준다.
