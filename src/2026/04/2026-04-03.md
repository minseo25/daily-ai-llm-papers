### 1. Universal YOCO for Efficient Depth Scaling

**트랙**: Efficient LLM / Inference / Long Context | **링크**: [arXiv](https://arxiv.org/abs/2604.01220)

제공된 abstract와 메타데이터를 기반으로 분석하겠습니다. 다만 논문 본문에 접근하여 더 구체적인 수치를 확인하고 싶었으나 웹 접근이 허용되지 않아, abstract에 담긴 정보를 최대한 활용하여 기술적으로 정확한 분석을 제공합니다.

📋 Problem Definition

Test-time scaling(추론 시 연산량 증가)이 LLM의 추론 및 에이전트 능력을 크게 향상시키고 있지만, 표준 Transformer 아키텍처는 추론 시 연산을 효율적으로 확장하는 데 구조적 한계를 가진다. 구체적으로, 기존의 반복(looping) 전략은 높은 연산 오버헤드를 수반하며, KV cache가 모델 깊이에 비례하여 선형적으로 증가하기 때문에 메모리 소비가 급격히 늘어난다. 이 논문은 모델의 표현력(depth)을 확장하면서도 KV cache 크기와 pre-filling 비용을 억제할 수 있는 아키텍처를 설계하는 문제를 다룬다.

📚 Background / Related Works

이 연구는 크게 두 갈래의 선행 연구를 결합한다. 첫째는 YOCO(You Only Cache Once) 아키텍처로, decoder-decoder 구조를 통해 전역 KV cache를 상수 크기로 유지하고 pre-filling을 선형 복잡도로 수행하는 효율적 추론 프레임워크이다(Sun et al., 2024). 둘째는 Universal Transformer(Dehghani et al., 2019) 계열의 재귀적 연산(recursive computation) 방식으로, 동일 파라미터 블록을 여러 번 반복 실행하여 파라미터 수 대비 표현 깊이를 증가시키는 접근이다. 또한 test-time scaling과 관련하여, 추론 시 연산량을 동적으로 조절하는 연구들(예: chain-of-thought prompting, adaptive computation)이 배경이 되며, 효율적 attention 메커니즘(linear attention, sliding window attention 등)에 대한 연구들도 관련 work에 해당한다.

🔬 Main Methodology

YOCO-U(Universal YOCO)는 YOCO의 decoder-decoder 아키텍처와 재귀적 연산을 결합한 구조이다. 핵심은 Universal Self-Decoder라는 컴포넌트로, 이 디코더는 파라미터 공유(parameter sharing)를 통해 동일한 레이어 블록을 여러 iteration에 걸쳐 반복 실행함으로써 실질적인 모델 깊이를 증가시킨다. 중요한 설계 결정으로, 이 반복 과정을 얕고 효율적인 attention 레이어(예: cross-attention이 아닌 효율적 self-attention)에 한정시켜 연산 오버헤드를 최소화한다. YOCO 프레임워크가 제공하는 상수 크기의 전역 KV cache와 선형 pre-filling 특성 위에, 부분적 재귀(partial recursion)가 제한된 추가 비용으로 표현 깊이를 강화하는 구조이다. 이 조합을 통해 YOCO 단독이나 재귀 연산 단독으로는 달성할 수 없는 시너지 효과, 즉 능력(capability)과 효율성(efficiency) 간의 유리한 트레이드오프를 실현한다. 토큰 활용도(token utility)와 스케일링 행동이 개선되면서도 효율적 추론이 유지되는 것이 핵심 기여이다.

🧪 Evaluation

실험은 일반 언어 벤치마크와 long-context 벤치마크 양쪽에서 수행되었다. YOCO-U는 두 평가 설정 모두에서 기존 표준 Transformer 및 개별 YOCO, 재귀적 모델 대비 높은 경쟁력(highly competitive)을 유지하는 것으로 보고되었으며, 특히 추론 효율성(KV cache 크기, pre-filling 속도) 측면에서 명확한 이점을 보였다. 구체적인 모델 크기나 벤치마크별 수치는 본문에 상세히 기술되어 있으나, abstract 수준에서는 "일반 및 long-context 벤치마크에서 highly competitive한 성능을 유지"하면서 "효율적 추론을 보장"한다는 결과가 제시되었다.

💡 Key Intuition & Lesson

이 논문의 핵심 인사이트는 "효율적 attention 아키텍처"와 "재귀적 연산"이라는 두 가지 독립적인 기법이 결합될 때 각각의 한계를 상호 보완하며 시너지를 낸다는 점이다. YOCO는 KV cache 효율성을, 재귀는 파라미터 효율적 깊이 확장을 제공하는데, 재귀를 효율적 attention 레이어에만 한정함으로써 재귀의 연산 비용 문제를 YOCO의 효율성이 흡수하는 구조가 된다. 이는 test-time scaling 시대에 단순히 모델을 키우거나 반복 횟수를 늘리는 것이 아니라, 아키텍처 수준에서 연산 구조를 재설계하는 것이 효율적 스케일링의 열쇠임을 시사한다.

### 2. Brainstacks: Cross-Domain Cognitive Capabilities via Frozen MoE-LoRA Stacks for Continual LLM Learning

**트랙**: LLM Post-training | **링크**: [arXiv](https://arxiv.org/abs/2604.01152)

📋 Problem Definition

기존 LLM 파인튜닝은 본질적으로 단일체(monolithic) 구조여서 세 가지 근본적 문제를 안고 있다. (1) 새로운 도메인을 추가하려면 처음부터 재학습하거나 catastrophic forgetting을 감수해야 하고, (2) 배포 후 특정 도메인 능력만 제거하거나 갱신할 수 없으며, (3) 추론 시 입력과 무관하게 모든 학습된 지식이 균일하게 적용되어 관련 전문성만 선택적으로 활성화할 방법이 없다. Brainstacks는 도메인 전문성을 동결된 MoE-LoRA 스택이라는 단일 아키텍처 원시 단위로 패키징하여, 도메인별 독립적 추가/제거/업데이트가 가능한 모듈형 지속 학습 시스템을 구현하고자 한다.

📚 Background / Related Works

MoE-LoRA 결합 연구로는 MoLoRA(Zadouri et al., 2023), MixLoRA(Li et al., 2024), LoRAMoE(Dou et al., 2024), SiRA(Zhu et al., 2023), HydraLoRA(Tian et al., 2024) 등이 있으나, 이들은 MoE를 FFN 레이어에만 적용하거나 어텐션에는 단일 LoRA를 사용하며, 지속 학습 기능이 없다. 어댑터 기반 지속 학습으로는 Progressive Neural Networks(Rusu et al., 2016), C-LoRA(Chen et al., 2025), Online-LoRA(Wei et al., 2024)가 있으나 어댑터를 가산적으로 합성(additive composition)하지 못하고, null-space 보호도 제공하지 않는다. Null-space 그래디언트 프로젝션 분야에서는 InfLoRA(Liang & Li, CVPR 2024), NESS(ICLR 2025), GPM(Saha et al., 2021)이 이전 태스크의 입력 표현에 대한 근사 null space를 구성하여 새 태스크 업데이트를 제약하는 접근을 취했으며, Brainstacks는 이 중 InfLoRA/NESS에 가장 가까운 randomized SVD 기반 프로젝션을 채택한다.

🔬 Main Methodology

Brainstacks는 다섯 가지 핵심 구성요소가 맞물린 아키텍처다. 첫째, 기본 빌딩 블록인 MoE-LoRA Delta 모듈은 트랜스포머의 7개 프로젝션(q, k, v, o, gate, up, down) 모두에 4개 전문가 중 top-2를 선택하는 Shazeer 스타일 노이즈 라우팅을 적용하며, QLoRA 4비트 양자화와 rsLoRA 스케일링(alpha/sqrt(r), 유효 스케일 4.0)을 결합한다. 둘째, 내부 루프(residual boosting)에서는 한 도메인 내에서 첫 번째 스택을 학습 후 동결하고, 두 번째 스택이 첫 번째가 포착하지 못한 잔차 오류를 학습하는 방식으로 단일 스택의 성능 한계를 돌파한다. 셋째, 외부 루프는 Chat->Code->Math->Medical->Reasoning 순의 커리큘럼 순서로 도메인을 순차 학습하며, 각 도메인 학습 전에 null-space 프로젝터를 계산한다. 넷째, null-space 프로젝션은 이전 도메인 검증 데이터 400개 샘플에서 동결 스택의 출력 델타를 수집하고 randomized SVD로 상위 64개 주성분 방향을 추출한 뒤, 활성 스택의 델타에서 해당 방향 성분을 수학적으로 제거(delta - delta dot P, P=V dot V^T)하여 이전 도메인 방향에 물리적으로 쓸 수 없게 하는 경성 기하학적 제약이다. 다섯째, 결과 기반 시그모이드 메타 라우터(약 2M 파라미터)는 도메인 레이블이 아닌 경험적 손실 측정을 통해 각 프롬프트에 최적인 도메인 조합을 발견하며, 시그모이드 게이팅으로 복수 스택의 동시 활성화를 허용한다.

🧪 Evaluation

TinyLlama-1.1B(4개 도메인, 9개 스택)와 Gemma 3 12B IT(5개 도메인, 10개 스택) 두 모델에서 검증했다. MoE-LoRA는 파라미터 수를 맞춘 단일 LoRA 대비 2.5배 빠른 수렴을 달성했고, residual boosting은 단일 스택의 성능 상한을 돌파했으며, 메타 라우터가 적용된 시스템은 게이팅 없이 모든 스택을 누적했을 때 파괴되는 생성 품질을 복구했다. 가장 주목할 결과는 의료 프롬프트가 97%의 경우에서 chat+math 스택으로 라우팅되었다는 것인데, 해당 스택에는 의료 데이터가 전혀 포함되어 있지 않음에도 불구하고 이러한 라우팅이 최적의 손실을 산출했다.

💡 Key Intuition & Lesson

이 논문의 핵심 발견은 도메인별로 학습된 스택이 실제로는 도메인 특화 지식이 아니라 전이 가능한 인지적 원시 능력(instruction-following 명확성, 수치 추론, 절차적 논리, chain-of-thought 구조)을 인코딩한다는 것이다. 의료 프롬프트가 의료 스택이 아닌 chat+math 스택으로 라우팅되는 현상은, 도메인이라는 레이블이 실제 학습되는 능력의 본질을 잘못 기술하고 있을 수 있음을 시사한다. 이는 LLM 파인튜닝에서 "도메인 전문성"이라고 부르는 것의 상당 부분이 사실은 도메인 간 공유되는 구조적 추론 능력의 조합이며, 결과 기반(outcome-based) 라우팅이 레이블 기반 라우팅보다 이러한 숨겨진 능력 구조를 더 정확히 포착한다는 실용적 교훈을 준다.
