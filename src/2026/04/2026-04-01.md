### 1. AdaptToken: Entropy-based Adaptive Token Selection for MLLM Long Video Understanding

**트랙**: Efficient LLM / Inference / Long Context | **링크**: [arXiv](https://arxiv.org/abs/2603.28696)

📋 Problem Definition

멀티모달 대규모 언어모델(MLLM)이 긴 영상을 이해할 때, 프레임 수 증가에 따른 메모리 비용과 컨텍스트 길이 제한이 핵심 병목이 된다. 기존 방법들은 짧은 클립 단위로 프레임이나 토큰에 점수를 매겨 선별하지만, 시간적으로 멀리 떨어진 클립 간의 관련성을 비교하는 원칙적 메커니즘이 없고, 충분한 증거가 모였을 때 처리를 중단하는 기준도 부재하다. AdaptToken은 이 두 가지 한계, 즉 전역적 관련성 비교와 조기 종료를 동시에 해결하고자 한다.

📚 Background / Related Works

긴 영상 이해를 위한 기존 접근은 크게 프레임 샘플링 기반(균등 샘플링, 키프레임 선택)과 토큰 압축 기반(FastV, LLaVA-PruMerge 등 시각 토큰 pruning/merging 기법)으로 나뉜다. VideoMME, LongVideoBench, MLVU 같은 벤치마크가 긴 영상 QA 평가를 위해 제안되었으며, Qwen2.5-VL, InternVL 등 최신 MLLM들이 기본 모델로 활용되고 있다. 특히 클립 단위 점수 부여 방식은 로컬 정보만 사용하므로 전역적 토큰 배분이 불가능하다는 문제가 이전 연구들에서 지적되어 왔다.

🔬 Main Methodology

AdaptToken은 학습 없이(training-free) 작동하는 프레임워크로, MLLM 자체의 불확실성(self-uncertainty)을 전역 제어 신호로 활용한다. 먼저 긴 영상을 여러 그룹으로 분할한 뒤, 각 그룹 내에서 cross-modal attention을 추출하여 시각 토큰의 중요도를 랭킹한다. 핵심 기여는 모델의 응답 엔트로피를 이용해 각 그룹의 프롬프트 관련성(prompt relevance)을 추정하는 것인데, 엔트로피가 낮은 그룹(모델이 확신하는 그룹)은 질문에 더 관련이 높다고 판단하여 더 많은 토큰 예산을 할당한다. 이 엔트로피 신호는 그룹 간 전역적 토큰 예산 배분을 가능하게 하며, 나아가 AdaptToken-Lite 변형에서는 모델의 확신도가 충분히 높아지면 나머지 그룹 처리를 건너뛰는 조기 종료(early stopping)를 지원한다. 이로써 로컬 클립 단위가 아닌 영상 전체에 걸친 적응적 토큰 선택이 가능해진다.

🧪 Evaluation

VideoMME, LongVideoBench, LVBench, MLVU의 4개 긴 영상 벤치마크에서, 7B부터 72B까지 다양한 크기의 MLLM(Qwen2.5-VL 등)을 기본 모델로 사용해 평가했다. AdaptToken은 Qwen2.5-VL 7B 기준 평균 +6.7점의 정확도 향상을 달성했으며, 최대 10,000 프레임의 극단적으로 긴 입력에서도 성능이 지속적으로 향상되는 스케일링 특성을 보였다. AdaptToken-Lite는 이에 준하는 성능을 유지하면서 추론 시간을 약 절반으로 줄였다.

💡 Key Intuition & Lesson

이 논문의 핵심 통찰은 모델 자체의 출력 엔트로피가 외부 스코어링 함수 없이도 입력의 관련성을 측정하는 자연스러운 신호가 된다는 점이다. 모델이 "얼마나 확신하는가"를 전역 제어 신호로 활용하면, 로컬 클립 간 비교 불가능 문제와 불필요한 계산 낭비 문제를 동시에 해결할 수 있다. 학습 없이 기존 MLLM에 바로 적용 가능하다는 점에서, 엔트로피 기반 적응적 계산량 조절(adaptive computation)이 긴 시퀀스 처리의 실용적 패러다임이 될 수 있음을 보여준다.

### 2. Kernel-Smith: A Unified Recipe for Evolutionary Kernel Optimization

**트랙**: LLM Post-training | **링크**: [arXiv](https://arxiv.org/abs/2603.28342)

📋 Problem Definition

LLM을 활용한 GPU 커널 자동 생성은 one-shot 방식의 한계로 인해 컴파일 실패, 정확성 오류, 성능 미달 등의 문제가 빈번하게 발생한다. 기존 접근법들은 단일 시도로 최적 커널을 생성하려 하기 때문에, 실제 하드웨어에서의 실행 피드백을 반복적으로 반영하는 최적화 루프가 부재하다. Kernel-Smith는 이 문제를 진화적(evolutionary) 탐색 에이전트와 진화 궤적 기반 후훈련(post-training)을 통합하여, 다양한 GPU 백엔드(NVIDIA Triton, MetaX MACA)에서 고성능 커널을 안정적으로 생성하는 프레임워크를 제안한다.

📚 Background / Related Works

LLM 기반 코드 생성 분야에서는 KernelBench가 GPU 커널 최적화 벤치마크로 활용되어 왔으며, Triton 언어를 대상으로 한 커널 생성 연구가 활발하다. 진화적 프로그램 탐색 관점에서는 population 기반 탐색과 LLM을 결합하는 접근(예: FunSearch, EvoCodeBench 류의 진화적 코드 최적화)이 선행 연구로 존재하며, 강화학습 기반 코드 생성에서는 DeepSeek-Coder, Qwen-Coder 계열 모델들이 경쟁 모델로 언급된다. 또한 SGLang, LMDeploy 같은 프로덕션 추론 시스템의 커널 최적화가 실용적 응용으로 연결되는 맥락이 있다.

🔬 Main Methodology

Kernel-Smith는 에이전트 측면과 훈련 측면의 두 축으로 구성된다. 에이전트 측면에서는 실행 가능한 커널 후보들의 population을 유지하면서, 컴파일 성공 여부, 정확성, speedup에 대한 구조화된 실행 피드백을 기반으로 반복 개선하는 evaluation-driven evolutionary search를 수행한다. 이때 top-performing 프로그램과 다양성(diversity)을 동시에 보존하는 archive를 활용하여 탐색의 안정성을 확보한다. 훈련 측면에서는 긴 진화 궤적(long-horizon evolution trajectory)을 step 단위의 지도학습 및 강화학습 신호로 변환하는데, 정확성을 보존하면서 높은 성능 개선(high-gain)을 달성한 revision만을 선별하여 모델이 one-shot 생성기가 아닌 진화 루프 내의 강력한 local improver로 최적화되도록 한다. 백엔드별로 Triton(NVIDIA)과 MACA(MetaX) 전용 평가 서비스를 구축하여 이기종 플랫폼 지원을 실현했다.

🧪 Evaluation

KernelBench의 NVIDIA Triton 백엔드에서 Kernel-Smith-235B-RL은 평균 speedup ratio 기준 state-of-the-art를 달성했으며, Gemini-3.0-pro와 Claude-4.6-opus를 포함한 프론티어 프로프라이어터리 모델들을 능가했다. MetaX MACA 백엔드에서는 30B 규모의 Kernel-Smith-MACA-30B가 DeepSeek-V3.2-think, Qwen3-235B-2507-think 등 훨씬 큰 규모의 모델들을 초과하는 성능을 보여, 파라미터 효율성과 이기종 플랫폼 적응력을 동시에 입증했다. 벤치마크를 넘어 SGLang과 LMDeploy 프로덕션 시스템에 실제 upstream contribution을 제출함으로써, 통제된 평가 환경에서 실제 배포까지의 전이 가능성을 실증했다.

💡 Key Intuition & Lesson

핵심 인사이트는 LLM을 단발성 코드 생성기로 사용하는 대신, 진화적 탐색 루프의 local improver로 재정의하고, 그에 맞게 훈련 데이터(진화 궤적에서 추출한 step-centric 신호)와 학습 목표(정확성 보존 + 성능 향상 revision 선별)를 설계해야 한다는 점이다. 이는 "에이전트 설계와 모델 훈련을 동일한 진화 프로토콜 아래 통합"하는 것이 핵심이며, 탐색 시 다양성 보존 archive와 구조화된 실행 피드백의 결합이 안정적 성능 향상의 열쇠임을 보여준다. 또한 30B 모델이 235B급 범용 모델을 능가한 결과는, 도메인 특화된 진화적 후훈련이 모델 규모 확장보다 더 효과적인 경로가 될 수 있음을 시사한다.

### 3. From System 1 to System 2: A Survey of Reasoning Large Language Models

**트랙**: LLM Post-training | **링크**: [arXiv](https://arxiv.org/abs/2502.17419)

📋 Problem Definition

기존의 기초 대형 언어 모델(LLM)은 System 1에 해당하는 빠르고 직관적인 의사결정에는 뛰어나지만, 복잡한 수학 증명이나 코드 생성처럼 단계별 논리적 추론(System 2)이 필요한 과제에서는 성능이 부족하다는 문제를 다룬다. 이 서베이는 System 1에서 System 2로의 전환이 어떻게 이루어지고 있는지, 즉 추론 특화 LLM(Reasoning LLM)이 어떤 방법론을 통해 구축되고 발전해왔는지를 체계적으로 정리하고 향후 방향을 제시하는 것을 목표로 한다.

📚 Background / Related Works

인지심리학에서 Daniel Kahneman이 제안한 System 1(빠르고 자동적 사고)과 System 2(느리고 의도적 사고)의 이중 프로세스 이론을 LLM 연구에 대응시키는 것이 이 서베이의 이론적 기반이다. 선행 연구로는 Chain-of-Thought(CoT) 프롬프팅을 제안한 Wei et al.(2022), Tree-of-Thoughts(ToT, Yao et al., 2023), Self-Consistency(Wang et al., 2023) 등 추론 시점(test-time)에서 사고 과정을 명시적으로 유도하는 기법들이 있다. 또한 강화학습 기반 후학습(post-training)으로 추론 능력을 내재화한 OpenAI o1/o3, DeepSeek-R1, Qwen-QwQ 등이 대표적인 추론 LLM으로 다뤄지며, 이들이 수학(AIME, MATH), 코딩(Codeforces), 과학(GPQA) 등에서 전문가 수준의 성과를 달성한 사례를 정리한다.

🔬 Main Methodology

이 서베이의 핵심 기여는 추론 LLM의 구축 방법론을 세 가지 축으로 체계화한 것이다. 첫째, 훈련 시점(training-time) 접근으로, 고품질 추론 데이터(long-CoT 데이터)를 활용한 지도학습(SFT)과 강화학습(RL) 기반 후학습을 구분한다. DeepSeek-R1은 대규모 RL(GRPO 알고리즘)만으로도 명시적 CoT 감독 없이 추론 능력이 창발(emergent)할 수 있음을 보였고, R1-Zero는 SFT 없이 순수 RL만으로도 자기 검증(self-verification)과 반성(reflection) 패턴이 자연 발생함을 입증했다. 둘째, 추론 시점(test-time/inference-time) 확장 기법으로, best-of-N 샘플링, beam search, Monte Carlo Tree Search(MCTS), 프로세스 보상 모델(PRM)을 활용한 탐색 전략을 정리한다. 셋째, 두 접근의 결합으로, 훈련 시 RL로 기본 추론 능력을 내재화하고 추론 시 탐색 전략으로 성능을 추가 향상시키는 하이브리드 방식을 논의한다. 또한 추론 LLM의 특징으로 긴 사고 사슬(long CoT), 자기 반성, 탐색과 역추적(backtracking) 등을 식별하고, 이를 통해 추론 정확도와 신뢰성이 어떻게 향상되는지 분석한다.

🧪 Evaluation

서베이에서 다루는 주요 벤치마크로는 수학 추론(MATH-500, AIME 2024, AMC), 코딩(Codeforces, SWE-bench, LiveCodeBench), 과학(GPQA Diamond), 일반 추론(ARC-AGI, MMLU-Pro) 등이 있다. 대표적 성과로 OpenAI o1은 AIME 2024에서 83.3%(상위 500등 수준), GPQA Diamond에서 78.0%를 달성했고, DeepSeek-R1은 AIME 2024에서 79.8%, MATH-500에서 97.3%로 o1에 근접하거나 일부 벤치마크에서 동등한 성능을 보였다. 서베이는 이러한 추론 LLM들이 기초 LLM 대비 수학과 코딩에서 비약적 성능 향상을 보이지만, 추론 토큰 증가에 따른 계산 비용 문제와 일부 상식 추론 과제에서의 과잉 사고(overthinking) 문제가 존재함을 지적한다.

💡 Key Intuition & Lesson

가장 핵심적인 인사이트는 추론 능력이 반드시 명시적 감독(supervised CoT 데이터)을 통해서만 학습되는 것이 아니라, 적절한 보상 설계와 대규모 강화학습만으로도 창발할 수 있다는 점이다(DeepSeek-R1-Zero의 사례). 또한 test-time compute scaling, 즉 추론 시점에서 더 많은 연산을 투입하면 모델 크기를 키우지 않고도 성능을 향상시킬 수 있다는 패러다임 전환이 중요한 교훈이며, 이는 향후 LLM 연구에서 학습 시점 확장(training-time scaling)과 추론 시점 확장(test-time scaling)의 최적 균형을 찾는 것이 핵심 과제가 될 것임을 시사한다.
