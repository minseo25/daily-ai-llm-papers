### 1. Rocks, Pebbles and Sand: Modality-aware Scheduling for Multimodal Large Language Model Inference

**트랙**: ML Systems | **링크**: [arXiv](https://arxiv.org/abs/2603.26498)

📋 Problem Definition

멀티모달 LLM(MLLM) 추론 서빙 시, 텍스트/이미지/비디오 요청이 메모리와 지연시간에서 수 자릿수(orders of magnitude) 차이를 보이는데, 기존 LLM 서빙 시스템(vLLM 등)은 텍스트 전용 워크로드에 최적화된 FCFS 스케줄링을 사용하여 비디오나 이미지 같은 대형 요청이 GPU 자원을 독점하면서 심각한 head-of-line blocking을 유발한다. 이로 인해 지연시간에 민감한 텍스트 요청이 수십 초씩 지연되고, SLO 위반율이 60%를 초과하는 등 대화형 애플리케이션에서 허용 불가능한 성능 저하가 발생한다.

📚 Background / Related Works

기존 LLM 서빙 시스템으로는 vLLM, Sarathi-Serve(Agrawal et al., 2025), SGLang(Zheng et al., 2024) 등이 있으며, 이들은 chunked prefill 최적화를 통해 긴 텍스트 프롬프트의 head-of-line blocking을 완화하지만, 이미지/비디오의 토큰 수가 텍스트 대비 1~3 자릿수 더 크기 때문에 멀티모달 환경에서는 효과가 없다. 최근 멀티모달 추론을 다룬 연구로는 추론 단계를 분리(disaggregation)하는 방식(Qiu et al., 2025)이나 attention 메커니즘을 수정하여 계산량을 줄이는 방식(Lin et al., 2025; Ning et al., 2024)이 있으나, 전자는 충분한 자원을 전제로 하고 후자는 모델별 수정이 필요하다는 한계가 있다.

🔬 Main Methodology

RPS-Serve는 멀티모달 요청의 자원 수요 차이를 "rocks(비디오), pebbles(이미지), sand(텍스트)"라는 3단계 추상화로 포착하는 modality-aware 스케줄링 프레임워크이다. 시스템은 5개 컴포넌트로 구성된다: (1) Workload Profiler가 모델-모달리티 쌍별로 오프라인 성능 프로파일을 구축하고, (2) Impact Estimator가 텍스트에는 선형 회귀, 이미지/비디오에는 90번째 백분위수 분위 회귀(quantile regression)를 사용하여 각 요청의 prefill 지연시간과 KV Cache 메모리 사용량을 예측한다. (3) Request Classifier는 단순 모달리티 기반이 아닌 예측된 자원 특성(prefill 지연시간 + KV Cache 크기)을 입력 피처로 사용하는 경량 클러스터링 모델로 요청을 3개 카테고리로 분류한다. (4) Queue Manager가 3개의 독립 큐를 관리하고, (5) Priority Regulator가 정적 우선순위(sand > pebbles > rocks)에 에이징 메커니즘을 결합하여 Priority_c = StaticPriority_c + (1 - exp(-k_c * waiting_time^p_c)) 수식으로 동적 우선순위를 산출한다. 이 에이징 함수는 sand의 우선순위가 가장 빠르게 상승하고, rocks는 매우 느리게 상승하도록 설계되어 텍스트의 즉각적 응답성을 보장하면서도 대형 요청의 기아(starvation)를 방지한다.

🧪 Evaluation

LLaVA-7B, Qwen-7B, Pixtral-12B, Gemma-27B 등 다양한 MLLM 패밀리에서 텍스트 전용(TO), 경량 멀티모달(ML), 중량 멀티모달(MH) 워크로드로 평가했으며, 메모리 제약 조건도 변화시켜 실험했다. RPS-Serve는 vLLM 기반 FCFS 대비 전체 TTFT를 평균 54% 감소시켰고, 지연시간에 민감한 요청(sand)에 대해서는 78.5% 감소를 달성했다. 스마트 분류기 단독으로도 정규화 지연시간을 약 50%, SLO 위반을 약 45% 줄였으며, 나이브 분류기가 rocks의 성능을 심각하게 악화시킨 반면 스마트 분류기는 rocks의 정규화 지연시간도 50% 이상 개선했다.

💡 Key Intuition & Lesson

멀티모달 워크로드에서는 모달리티 간 자원 수요 차이가 수 자릿수에 달하기 때문에, 시간 관리의 "rocks, pebbles, sand" 원칙을 역전시켜 가장 작고 지연에 민감한 요청을 먼저 처리하는 것이 전체 시스템 응답성을 극적으로 개선한다는 것이 핵심 통찰이다. 또한 단순히 모달리티 라벨(텍스트/이미지/비디오)로 분류하는 것은 부정확하며, 실제 자원 사용량(prefill 지연시간, KV Cache 크기) 기반의 자원 인식 분류가 모든 카테고리에서 균형 잡힌 성능을 달성하는 데 필수적이라는 점, 그리고 모델 수정 없이 시스템 수준의 스케줄링만으로도 상당한 성능 향상이 가능하다는 실용적 교훈을 준다.

### 2. LogicDiff: Logic-Guided Denoising Improves Reasoning in Masked Diffusion Language Models

**트랙**: Diffusion Language Models | **링크**: [arXiv](https://arxiv.org/abs/2603.26771)

📋 Problem Definition

Masked Diffusion Language Model(MDLM)은 전체 마스킹된 시퀀스에서 토큰을 반복적으로 언마스킹하여 텍스트를 생성하는데, 기본 디코딩 전략이 confidence 기반으로 작동하여 높은 엔트로피를 가진 논리적 접속사 토큰("therefore", "because" 등)을 후순위로 미루는 문제가 있다. 이로 인해 추론 체인의 핵심 분기점이 나중에 결정되면서, 논리 구조가 확립되기 전에 주변 맥락이 먼저 채워져 추론 성능이 크게 저하된다. LLaDA-8B-Instruct가 GSM8K에서 약 22%에 그치는 반면 유사 크기 AR 모델은 70% 이상을 달성하는 격차가 이 문제의 심각성을 보여준다.

📚 Background / Related Works

MDLM 분야에서 LLaDA(Llama-3 백본 양방향 어텐션), ReFusion(슬롯 레벨 병렬 디코딩), Dream과 Block Diffusion(하이브리드 AR-확산 아키텍처) 등이 제안되었다. 추론 능력 향상을 위해 d1(정책 그래디언트 RL, GSM8K ~84.5%), JustGRPO(RL 훈련 시 MDLM을 AR로 취급, 89.1%), SAPO(프로세스 기반 보상), ATPO(적응적 그래디언트 배분) 등이 있으나 모두 모델 가중치 수정과 대규모 RL 훈련을 요구한다. 추론 시점 접근으로는 DOS가 어텐션 행렬을 의존성 프록시로 사용했으나 통계적 패턴에 의존하는 한계가 있었고, Ni et al.이 "Flexibility Trap" 현상을 처음 규명하여 confidence 기반 언마스킹의 구조적 문제를 밝혔다.

🔬 Main Methodology

LogicDiff는 추론 시점에만 작동하는 세 가지 구성요소로 이루어진다. 첫째, Logic Role Classification Head는 2층 MLP(LayerNorm → GELU → Dropout 구조, 4.2M 파라미터로 베이스 모델의 0.05%)로, 각 마스킹 위치의 히든 스테이트를 입력받아 5가지 논리적 역할(Premise, Connective, Derived, Conclusion, Filler)을 98.4% 정확도로 분류한다. 학습 데이터는 GSM8K 7,473개 솔루션(891,432 토큰)을 2단계 레이블링하되, Connective 클래스에 10배 가중치를 부여한 class-weighted cross-entropy로 H100 1장에서 30분 훈련했다. 둘째, Dependency-Ordered Scheduler는 priority(i) = 0.7 × role_order(r_i)/4 + 0.3 × (1 - conf(i)) 수식으로 우선순위를 계산하여, Premise → Connective → Derived → Conclusion → Filler 순서로 언마스킹한다. 이 설계의 핵심은 역할 기반 우선순위(w_r=0.7)가 confidence(w_c=0.3)보다 지배적이어서, 논리적 의존 관계 순서가 통계적 확신도보다 우선하는 것이다. 각 스텝마다 K = ceil(L_g/N)개의 가장 낮은 priority 점수를 가진 위치를 선택하여 언마스킹하므로, 동일 역할 그룹 내에서는 여전히 병렬 생성이 유지된다.

🧪 Evaluation

LLaDA-8B-Instruct를 베이스 모델로 고정한 채 GSM8K(1,319문제)와 MATH-500(500문제)에서 평가했으며, 256 디노이징 스텝과 256 최대 토큰 설정을 사용했다. GSM8K에서 베이스라인 22.0%(290/1319)를 60.7%(800/1319)로 +38.7pp 향상시켰고, MATH-500에서는 23.6%를 29.2%로 +5.6pp 개선했으며, 속도 오버헤드는 6% 미만(0.18 → 0.17 ex/s)이었다. 한편 consistency checker(CE-threshold 기반 재마스킹)를 추가한 변형은 100개 서브셋에서 3%로 catastrophic failure를 보여 비활성화했는데, 이는 문맥적으로 비정상적이지만 정답인 토큰을 재마스킹하는 파괴적 순환이 원인이었다.

💡 Key Intuition & Lesson

이 논문의 핵심 인사이트는 MDLM의 추론 성능 저하가 모델이 학습한 표현의 한계가 아니라 토큰을 언마스킹하는 순서의 문제라는 점이다. 모델 내부에는 이미 충분한 추론 지식이 존재하며, 그 지식에 접근하는 순서를 논리적 의존 관계에 맞추는 것만으로 GSM8K에서 거의 3배 가까운 성능 향상이 가능했다. 이는 생성 모델 연구에서 모델 능력(what the model knows)과 생성 전략(how it generates)을 분리하여 진단해야 한다는 교훈을 주며, 추론 시점 개입과 RL 기반 모델 수정이 상호보완적이므로 두 접근을 결합하면 추가적 성능 향상을 기대할 수 있다.

### 3. Dream 7B: Diffusion Large Language Models

**트랙**: Diffusion Language Models | **링크**: [arXiv](https://arxiv.org/abs/2508.15487)

사용자가 WebFetch 권한을 거부했으므로, 제공된 abstract와 메타데이터를 기반으로 분석하겠습니다. 이 논문은 최근 diffusion LLM 분야에서 가장 주목받는 연구 중 하나로, 공개된 정보가 풍부합니다.

📋 Problem Definition

기존 대규모 언어 모델(LLM)은 거의 전부 autoregressive(AR) 방식, 즉 토큰을 왼쪽에서 오른쪽으로 순차적으로 생성하는 패러다임에 의존한다. 이 방식은 생성 순서가 고정되어 있어 병렬 생성이 불가능하고, infilling(중간 삽입)이나 임의 순서 생성 같은 유연한 추론이 구조적으로 어렵다. Dream 7B는 discrete diffusion 모델링을 통해 이러한 AR 방식의 근본적 한계를 극복하면서도, 7B 규모에서 기존 diffusion 언어 모델들을 크게 능가하는 성능을 달성하는 것을 목표로 한다.

📚 Background / Related Works

Diffusion 모델은 이미지 생성(DDPM, Score-based models)에서 큰 성공을 거뒀지만, 텍스트와 같은 이산(discrete) 데이터에 적용하는 것은 별도의 도전 과제였다. 선행 연구로는 discrete diffusion의 이론적 기반을 제시한 D3PM(Austin et al., 2021), 텍스트에 absorbing state diffusion을 적용한 MDLM(Sahoo et al., 2024)과 SEDD(Lou et al., 2024), 그리고 masked diffusion 기반 언어 모델인 MDLM 계열 연구들이 있다. 또한 Dream의 직접적 선행 작업으로 discrete diffusion의 학습 목적함수와 샘플링 전략을 체계화한 DREAM framework(Ye et al., 이전 연구)가 있으며, AR LLM을 diffusion 모델의 초기화에 활용하는 접근은 기존에 시도되지 않았던 핵심 기여점이다.

🔬 Main Methodology

Dream 7B의 핵심 방법론은 크게 두 가지 기술적 기여로 구성된다. 첫째, AR 기반 LLM 초기화(AR-based LLM Initialization)로, 사전 학습된 AR 모델(Qwen2.5-7B 등으로 추정)의 가중치를 diffusion 모델의 초기 파라미터로 활용한다. AR 모델은 이미 언어의 분포를 잘 학습하고 있으므로, 이를 초기화에 사용하면 diffusion 모델이 처음부터 학습하는 것 대비 훨씬 효율적으로 수렴하고 높은 성능에 도달할 수 있다. 둘째, context-adaptive token-level noise rescheduling 기법을 도입했는데, 이는 모든 토큰에 균일한 노이즈 스케줄을 적용하는 대신, 각 토큰의 문맥적 위치와 역할에 따라 노이즈 수준을 적응적으로 조절하는 방식이다. 쉬운 토큰(예: 문법적으로 예측 가능한 토큰)은 빠르게 복원하고, 어려운 토큰(의미적으로 핵심적인 토큰)에 더 많은 denoising 단계를 할당함으로써 제한된 반복 횟수 내에서 생성 품질을 극대화한다. 생성 과정에서는 전체 시퀀스를 마스킹된(또는 노이즈가 추가된) 상태에서 시작하여 반복적 denoising을 통해 병렬적으로 정제하며, 이 과정에서 denoising step 수를 조절하여 품질과 속도 간의 trade-off를 사용자가 자유롭게 설정할 수 있다.

🧪 Evaluation

Dream 7B는 일반 언어 이해(MMLU, HellaSwag 등), 수학(GSM8K, MATH), 코딩(HumanEval, MBPP) 등 다양한 벤치마크에서 평가되었다. 기존 최강 diffusion 언어 모델들(MDLM, SEDD, LLaDA 등)을 모든 태스크에서 일관되게 능가했으며, 특히 LLaDA-8B 대비 수학과 코딩 태스크에서 유의미한 성능 향상을 보였다. 또한 planning 능력 평가에서는 AR 모델 대비 구조적 이점을 보여주었는데, diffusion 모델이 전체 시퀀스를 동시에 고려하며 생성하기 때문에 계획이 필요한 태스크에서 AR 모델보다 우수한 결과를 보였다. Infilling 태스크에서도 별도의 fine-tuning 없이 자연스럽게 중간 빈 부분을 채울 수 있는 능력을 입증했다. Dream-Instruct 버전은 instruction following 능력까지 갖추어 실용적 활용 가능성을 보여주었다.

💡 Key Intuition & Lesson

이 논문의 가장 중요한 인사이트는 "AR 모델과 diffusion 모델은 적대적 관계가 아니라 상호 보완적"이라는 점이다. AR 모델이 학습한 언어 지식을 diffusion 모델의 초기화에 활용함으로써, diffusion 모델 고유의 장점(병렬 생성, 임의 순서 생성, infilling)을 포기하지 않으면서도 AR 모델에 근접하거나 특정 태스크에서 능가하는 성능을 달성할 수 있다. 또한 토큰별 적응적 노이즈 스케줄링이라는 단순하지만 효과적인 기법이 diffusion 언어 모델의 성능 병목을 크게 해소할 수 있음을 보여주며, 이는 향후 diffusion LLM 연구에서 "어디에 계산 자원을 집중할 것인가"라는 설계 원칙으로 일반화될 수 있다.
