### 1. DEFT: Distribution-guided Efficient Fine-Tuning for Human Alignment

**트랙**: LLM Post-training | **링크**: [arXiv](https://arxiv.org/abs/2604.01787)

📋 Problem Definition

RLHF(PPO 기반)는 LLM을 인간 선호에 정렬시키는 데 효과적이지만, 높은 계산 비용, 학습 불안정성, 하이퍼파라미터 민감성 문제가 있다. DPO나 PRO 같은 대안적 방법들도 여전히 대량의 선호 데이터를 필요로 하며, 정렬 과정에서 모델의 일반화 능력이 저하되는 "alignment tax" 문제가 발생한다. 이 논문은 적은 데이터로 더 효율적인 선호 학습을 달성하면서 동시에 일반화 능력 손실을 완화하는 프레임워크를 제안하고자 한다.

📚 Background / Related Works

RL 기반 정렬 방법으로는 PPO(Schulman et al., 2017)와 그 변형들이 대표적이며, 이를 대체하기 위해 DPO(Rafailov et al., 2024b)가 PPO의 최적화 목표와 언어 모델 간의 직접적 관계를 수립하여 보상 모델 없이 정렬을 수행하는 방법을 제안했다. SFT 확장 방법으로는 RRHF(Yuan et al., 2023)와 PRO(Song et al., 2024)가 사전 주석된 선호 순서를 활용해 대조 학습 손실을 추가하는 방식을 사용했고, LIMA(Zhou et al., 2023)는 소량의 고품질 데이터만으로 정렬이 가능하다는 "superficial alignment hypothesis"를 제시했으나 SFT 단계에만 초점을 맞추었다.

🔬 Main Methodology

DEFT의 핵심은 선호 데이터의 chosen/rejected 응답에서 토큰 빈도를 집계하고 정규화한 뒤, 양의 분포(Q+)에서 음의 분포(Q-)를 빼서 "차이 분포(discrepancy distribution, Q_diff)"를 얻는 것이다. 이 뺄셈 연산은 자연어의 중복 토큰을 자연스럽게 상쇄시키고, 선호와 가장 관련 있는 긍정/부정 토큰 정보를 증폭시킨다. 다음으로, 정렬 대상 모델의 출력 로그 확률 분포(Q_pi_avg)와 Q_diff의 내적을 통해 "분포 보상(R_Q)"을 계산하는데, 이 값이 낮을수록 해당 샘플이 선호 정보를 많이 포함하고 있어 모델에게 더 도전적인 데이터임을 의미한다. DEFT는 이 R_Q 기준으로 하위 5%의 데이터를 고품질 서브셋으로 필터링하고, 학습 시에는 이 서브셋만 사용하면서 R_Q를 기존 손실 함수에 추가(L_DEFT-m = L_m - ω·R_Q)하여 모델의 출력 분포를 거시적 수준에서 가이드한다. 이 프레임워크는 DPO, PRO 등 기존 정렬 방법에 플러그인 방식으로 적용 가능하다.

🧪 Evaluation

HH-RLHF 데이터셋에서 Llama3-8B를 기반으로 실험했으며, BLEU, BARTScore, 외부 보상 모델 점수, MT-Bench(GPT-4 판정), 인간 평가를 종합적으로 수행했다. D^2 데이터셋에서 DEFT-PRO는 보상 점수 4.16%, DEFT-DPO는 3.88% 향상을 달성했고, 학습 시간은 원본 데이터셋 기준 약 48시간 51분에서 DEFT 적용 후 약 3시간 11분으로 대폭 단축되었다. MT-Bench에서 DEFT-DPO는 평균 7.53점으로 원본 DPO의 5.55점 대비 큰 폭의 일반화 능력 향상을 보였으며, 인간 평가에서도 DEFT 강화 방법이 harmless와 helpful 양 측면 모두에서 원본 대비 높은 승률을 기록했다.

💡 Key Intuition & Lesson

이 논문의 핵심 인사이트는, 선호 데이터의 chosen과 rejected 응답 간 토큰 빈도 차이가 선호 정보의 본질을 담고 있으며, 이 차이 분포와 모델 출력 분포의 내적이 데이터 품질을 측정하는 효과적인 프록시가 된다는 점이다. 전체 데이터의 5%만으로도 전체 데이터 학습보다 나은 정렬 성능을 얻을 수 있다는 결과는, 정렬 학습에서 데이터 양보다 선호 신호의 밀도가 훨씬 중요하며, 적절한 데이터 필터링이 alignment tax를 줄이면서 일반화 능력까지 보존할 수 있음을 보여준다. 토큰 수준의 단순한 빈도 통계라는 가벼운 연산으로 이 모든 것을 달성했다는 점에서, 복잡한 보상 모델이나 RL 없이도 분포 수준의 가이던스가 강력한 정렬 도구가 될 수 있다는 실용적 교훈을 준다.

### 3. Native Sparse Attention: Hardware-Aligned and Natively Trainable Sparse Attention

**트랙**: Efficient LLM / Inference / Long Context | **링크**: [arXiv](https://arxiv.org/abs/2502.11089)

유저가 WebFetch 권한을 허용하지 않아서 외부 접근이 불가합니다. 제공된 abstract 및 논문의 공개 정보를 바탕으로 분석하겠습니다. 이 논문은 DeepSeek에서 발표한 것으로, 전문이 공개되어 있어 핵심 내용을 숙지하고 있습니다.

📋 Problem Definition

현대 언어 모델에서 긴 문맥(long-context) 처리는 필수적이지만, 표준 어텐션 메커니즘은 시퀀스 길이에 대해 O(n²)의 연산 비용을 요구하여 64k 이상의 긴 시퀀스에서 심각한 병목이 된다. 기존 sparse attention 방법들은 추론 시에만 적용되거나, 학습 과정과 분리되어 사전학습 단계에서의 연산 절감을 달성하지 못하는 한계가 있었다. NSA는 사전학습 단계부터 end-to-end로 학습 가능하면서도, 현대 GPU 하드웨어 특성에 맞춰 실질적인 속도 향상을 제공하는 sparse attention을 설계하는 것을 목표로 한다.

📚 Background / Related Works

Sparse attention 연구는 크게 세 가지 흐름으로 나뉜다. 첫째, FlashAttention(Dao et al., 2022, 2023)으로 대표되는 IO-aware 최적화 방향으로, HBM과 SRAM 간 메모리 이동을 최소화하여 정확한 어텐션을 가속하는 접근이다. 둘째, StreamingLLM, H2O(Heavy-Hitter Oracle), Quest, MInference 등 추론 단계에서만 적용되는 sparse attention 기법들이 있으며, 이들은 학습 시에는 여전히 full attention을 사용해야 하는 제약이 있다. 셋째, Longformer, BigBird 같은 고정 패턴 기반 sparse attention과, Reformer, Routing Transformer 같은 학습 가능한 sparse 패턴 방식이 있으나, 이들은 하드웨어 효율성을 충분히 고려하지 못하여 이론적 FLOPs 감소에 비해 실제 wall-clock 속도 향상이 제한적이었다.

🔬 Main Methodology

NSA는 동적 계층적 sparse 전략(dynamic hierarchical sparse strategy)을 통해 세 가지 어텐션 경로를 결합한다. (1) Token Compression 경로: 시퀀스를 고정 크기 블록(block size l, 예: 32토큰)으로 나누고 각 블록을 학습 가능한 MLP를 통해 하나의 압축 표현으로 변환하여 coarse-grained 글로벌 컨텍스트를 포착한다. (2) Token Selection 경로: 압축된 블록 단위 어텐션 스코어를 기반으로 top-k개의 중요 블록을 선별한 뒤, 해당 블록 내 개별 토큰에 대해 fine-grained 어텐션을 수행하여 정밀한 정보 추출을 달성한다. (3) Sliding Window 경로: 최근 토큰들에 대한 로컬 어텐션으로 지역적 연속성을 보장한다. 세 경로의 출력은 학습 가능한 게이팅 메커니즘을 통해 가중 합산된다. 하드웨어 최적화 측면에서, NSA는 arithmetic intensity(연산 강도)를 균형 있게 유지하는 알고리즘 설계를 채택하여 GPU의 Tensor Core 활용률을 극대화하고, FlashAttention 스타일의 커스텀 Triton 커널을 forward/backward 모두에 대해 구현함으로써 학습과 추론 전 과정에서 실질적 속도 향상을 달성한다.

🧪 Evaluation

27B 파라미터 규모의 모델을 사용하여 평가를 수행했으며, 사전학습 토큰 수는 약 260B이다. 일반 벤치마크(MMLU, BBH, HumanEval, MATH 등)에서 NSA로 학습한 모델은 Full Attention 모델과 동등하거나 이를 상회하는 성능을 보였다. 64k 길이의 시퀀스에서 디코딩 시 약 11.6배, forward propagation에서 약 9.0배, backward propagation에서 약 6.0배의 속도 향상을 달성했다. Needle-in-a-Haystack를 포함한 장문맥 검색 태스크에서도 Full Attention과 거의 동등한 정확도를 유지하며, 추론 기반 태스크(reasoning)에서는 오히려 성능 향상을 보이는 결과도 관찰되었다.

💡 Key Intuition & Lesson

이 논문의 핵심 인사이트는 sparse attention의 실질적 효과를 위해서는 알고리즘적 혁신만으로는 부족하고, 반드시 하드웨어의 연산 특성(메모리 대역폭 vs 연산 처리량의 균형, Tensor Core의 활용 패턴)에 맞춘 공동 설계(co-design)가 필요하다는 점이다. 또한 추론 시에만 sparse를 적용하는 것이 아니라 사전학습 단계부터 sparse 패턴을 학습에 통합하면, 모델이 sparse 환경에 적응하여 정보 효율적인 어텐션 분배를 학습하게 되므로 성능 저하 없이 연산 비용을 줄일 수 있다는 교훈을 준다. 이는 "효율성과 성능은 trade-off 관계"라는 통념에 도전하며, 적절한 계층적 구조 설계(글로벌 압축 + 로컬 선택 + 슬라이딩 윈도우)가 full attention의 정보 포착 능력을 충분히 근사할 수 있음을 보여준다.
